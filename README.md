# 화물지킴이 (Cargo Guardian System)

2026 가천대학교 창의적 종합설계 아이디어 공모전 출품작 — 화물 적재 상태(기울기·장력·이탈량)를 실시간으로 감지해 위험 상황을 경보하는 IoT 화물 안전 모니터링 시스템입니다.

**3조 | 강현서 · 성준하 · 이채원**

## 개요

ESP32 기반 센서 모듈이 화물의 기울기 변화율(MPU6050), 래싱벨트 장력 변화율(로드셀 + HX711), 위치 이탈량(VL53L1X)을 실시간으로 측정하고, 실험 데이터로 도출한 임계값을 기준으로 위험 상황을 판단해 경보합니다. 절대값이 아닌 영점 대비 변화율(%) 방식을 채택해 화물의 종류·무게와 무관하게 동일한 임계값을 적용할 수 있도록 설계했습니다.

자세한 실험 설계와 임계값 도출 과정은 [docs/화물지킴이_실험데이터_분석보고서.md](docs/화물지킴이_실험데이터_분석보고서.md)를 참고하세요.

## 폴더 구조

```
firmware/           하드웨어(ESP32/Arduino) 코드
  cargo_guardian_code_v6.ino   최신 버전
  legacy/                       이전 버전 (v1~v5, ESP32 초기 버전)
python/            센서 데이터 수신·저장 및 분석용 파이썬 스크립트
data/실험데이터/     주행 시나리오별 센서 실험 원본 데이터 (xlsx)
docs/              설계매뉴얼, 실험 보고서, 발표자료, 로직 흐름도 등
docs/images/       센서/시계열 데이터 분석 결과 이미지
```

- **최신판**: [firmware/cargo_guardian_code_v6.ino](firmware/cargo_guardian_code_v6.ino)

## 실험 데이터

박스형/파이프형 적재물 × 무게(가벼움/중간/무거움) × 주행 상황(정상, 급제동, 급커브, 노면충격, 벨트 이완 등) 조합으로 수집한 약 3,370행의 센서 데이터입니다. 자세한 실험 설계는 분석 보고서를 참고하세요.
