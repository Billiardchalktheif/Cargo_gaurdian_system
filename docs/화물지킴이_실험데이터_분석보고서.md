## 1. 실험 목적

본 실험은 화물지킴이 시스템의 핵심 판단 기준인 임계값(Threshold)을 데이터 기반으로 도출하기 위해 수행되었다. 단순 경험치가 아닌 실험적 근거를 바탕으로 오경보율과 실보율을 동시에 최소화하는 최적 임계값을 산출하는 것을 목표로 하였다.

---

## 2. 실험 환경 및 장비

### 2-1. 센서 구성

| 센서 | 모델 | 측정 대상 | 통신 방식 |
|------|------|---------|---------|
| 자이로/가속도 | MPU6050 | 화물 기울기 변화율 | I2C |
| 장력 | S형 로드셀 + HX711 | 래싱벨트 장력 변화 | Digital |
| 거리 | VL53L1X | 화물 위치 이탈량 | I2C |

### 2-2. 데이터 수집 시스템

ESP32에서 센서 데이터를 읽어 Wi-Fi UDP 통신으로 노트북에 전송하고, Python 스크립트가 이를 수신하여 엑셀 파일로 실시간 자동 저장하는 구조를 구성하였다.

- 샘플링 주기: 200ms
- 이동평균 필터: 5개 샘플 평균
- 데이터 포맷: 시간 / raw값 / 퍼센트 변화율 / 점수 / 경보상태

### 2-3. 퍼센트 방식 채택 이유

절대값 방식은 화물의 무게와 종류에 따라 임계값을 매번 재설정해야 하는 문제가 있다. 이를 해결하기 위해 영점 대비 변화율(%) 방식을 채택하였다.

변화율(%) = (현재값 - 영점값) / 영점값 x 100

이 방식을 통해 화물의 종류와 무게에 관계없이 영점 설정 한 번으로 동일한 임계값을 적용할 수 있다.

## 5. 임계값 도출 과정

### 5-1. 도출 방법론

정상 구간 데이터의 95퍼센타일을 오경보 기준선으로 설정하고, 위험 상황 데이터의 95퍼센타일을 감지 기준선으로 설정하여 두 구간 사이에서 임계값을 역산하였다.

### 5-2. 최종 확정 임계값

자이로 (정상 207% / 위험 최대 550% 사이)
- TILT_MINOR = 3.00 (300% → 경미, 1점)
- TILT_MAJOR = 4.00 (400% → 심각, 2점)

거리 (정상 6.8~8% / 위험 최대 127% 사이)
- DIST_MINOR = 0.15 (15% → 경미, 1점)
- DIST_MAJOR = 0.30 (30% → 심각, 2점)

장력 (벨트 이완 감지 기반)
- TENSION_MINOR = 0.50 (50% 감소 → 경미, 2점)
- TENSION_MAJOR = 0.80 (80% 감소 → 심각, 4점)

### 5-3. 센서별 축적 감지 횟수

순간적인 노이즈와 실제 위험 상황을 구분하기 위해 센서별 독립 축적 감지 방식을 적용하였다. 이는 소방설비의 축적형 감지기 원리와 동일하다.

| 센서 | 축적 횟수 | 시간 | 설정 이유 |
|------|---------|------|---------|
| 자이로 | 3회 | 0.6초 | 급격한 기울기 변화 빠르게 감지 |
| 거리 | 5회 | 1.0초 | 중간 반응속도 |
| 장력 | 7회 | 1.4초 | 벨트 이완은 서서히 진행 |

## 6. 경보 판정 로직 (총점제)

### 6-1. 센서별 배점

| 센서 | 역할 | 경미 | 심각 | 최대 점수 |
|------|------|------|------|---------|
| 장력 | 메인 | 2점 | 4점 | 4점 |
| 자이로 | 보조 | 1점 | 2점 | 2점 |
| 거리 | 보조 | 1점 | 2점 | 2점 |
| 합계 | | | | 8점 |

### 6-2. 경보 단계

| 총점 | 단계 | 동작 |
|------|------|------|
| 0~2점 | NORMAL | 정상 표시 |
| 3~5점 | WARNING | LCD 경고 + 부저 간헐 |
| 6점 이상 | DANGER | LCD 위험 + 부저 연속 |

### 6-3. 장력을 메인으로 설정한 이유

- 자이로: 차체 기울기 측정 (간접적 징후)
- 거리: 화물 위치 이탈 감지 (이미 이탈 시작 후)
- 장력: 래싱벨트 직접 측정 (이탈 전 조기 감지 가능)

장력 센서가 화물 이탈 전 가장 먼저 반응하므로 최대 4점의 높은 배점을 부여하였다.
